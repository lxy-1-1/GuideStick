## 5. 项目整体关系

这个项目可以理解为三部分：

    硬件端负责采集图像和执行动作。
    后端负责提供接口和完成识别。
    安卓端负责交互、展示和用户操作。

典型流程：

    导盲杖拍照
    后端识别
    返回结果
    语音播报

另一个典型流程：

    安卓点击功能
    调用后端接口
    后端返回状态
    硬件执行对应动作

## 6. 一句话总结

这是一个基于 ESP32-CAM、Django、YOLOv5 和 Android Java 的智能导盲杖项目。

硬件端负责采集和执行，后端负责识别和接口服务，安卓端负责用户交互和展示。
