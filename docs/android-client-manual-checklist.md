# 智途 Android 客户端真机验收清单

## 准备

- 手机和运行 Django 的电脑连接同一局域网。
- 服务器使用 `python manage.py runserver 0.0.0.0:8000` 启动。
- 在“我的 -> 使用设置”填写电脑局域网地址，例如 `http://172.20.10.3:8000/`，点击“测试连接”。
- ESP32-CAM 固件中的 `SERVER_BASE_URL` 与手机设置的地址保持一致，并重新烧录修改后的固件。

## 账号与首页

- 注册失败时显示服务器返回的明确原因，成功后可登录。
- 已登录状态重新打开应用时直接进入首页。
- 首页显示服务器在线状态；断开电脑网络后显示未连接，恢复后可刷新。
- 首页可进入出行助手、红绿灯识别、寻找导盲杖和紧急呼叫。

## 出行助手

- 文字提问能得到 DeepSeek 回答，失败后输入内容仍保留。
- 麦克风权限允许后可以语音输入；拒绝权限时有明确提示。
- 自动朗读开启时播报回答，工具栏停止按钮能立即停止。
- 清空按钮弹出确认框并清除当前对话。
- “刚才识别到了什么”能结合最近一次识别结果回答。

## 红绿灯识别

- 首次进入正确申请相机权限，拒绝时显示提示。
- 拍照期间按钮不可重复点击，并显示处理中状态。
- 红灯、绿灯、未知三种结果的文字、颜色和指令正确。
- 回到首页后能看到最近识别结果和更新时间。

## 导盲杖联动

- 点击寻找后，手机提示“寻杖信号已发送”。
- ESP32-CAM 每秒轮询 `find_stick_status/`，收到 `true` 后触发固定语音或蜂鸣提示。
- 紧急按键触发后，手机显示检测到信号，并在确认/授权后拨打预设联系人。
- 无电话功能的设备不会崩溃，而是显示不支持电话功能。

## 位置、设置与无障碍

- 允许定位权限后显示地址、经纬度、精度和更新时间；刷新按钮可重新定位。
- 关闭系统定位、拒绝权限、无网络解析地址时均有可理解的状态提示。
- 大字模式切换后页面文字明显放大，所有按钮和文字仍完整显示。
- 关闭自动朗读后助手不再自动播报；关闭触觉反馈后按钮不再振动。
- 修改服务器地址并保存后，登录、识别、助手和寻杖均使用新地址。

## 账号与隐私

- “关于我们”只显示团队名称“智途”和口号“智行无碍，途达万家”，不出现成员个人信息。
- 退出登录后回到登录页，账号令牌被清除，但服务器地址、无障碍设置和紧急联系人保留。
- DeepSeek API 密钥不出现在 APK、设置页或网络请求参数中，只保存在 Django 服务器环境变量中。

## 紧急定位短信实机验收

- 在“我的”页面预先保存可接收短信和电话的紧急联系人，紧急页只展示该号码。
- 首次点击“发送定位短信并呼叫”时，允许电话、短信和定位权限；授权后确认 APP 立即进入通话，并由手机 SIM 卡发送求助短信。
- 定位可用时，短信应包含经纬度、定位精度和可点击的地图链接；核对链接位置与手机当前位置基本一致。
- 关闭手机定位后再次测试，确认电话仍会拨出，短信明确写明“无法获取定位”。
- 分别拒绝短信权限、电话权限和定位权限，确认已授权的安全动作仍会执行，APP 不崩溃。
- 无 SIM 卡、欠费或系统限制场景只验证 APP 有清晰失败提示，不将“已提交发送”当作“对方已收到”。
- 通过导盲杖紧急按键触发后，确认短信和电话只执行一次；通话返回后不会每 5 秒重复触发。

## 地图定位页实机验收

- 地图应自动占满地址信息区之外的剩余高度，普通竖屏不再出现大块空白区域。
- 允许手机定位权限后，地图区域显示 OpenStreetMap 和当前位置标记，标记与下方经纬度一致。
- 点击“刷新”后，地址、坐标、精度、更新时间和地图标记同步更新。
- 点击“打开地图”后，优先进入手机已安装的地图应用；没有地图应用时进入 OpenStreetMap 网页。
- 断开互联网后，地图区域显示“地图暂时无法加载”，下方已有地址和坐标仍然可读。
- 关闭定位或拒绝定位权限时，不显示伪造标记，“打开地图”按钮保持不可用。
- 检查地图缩放、上下滚动和底部导航互不遮挡，开启大字模式后按钮文字仍完整显示。
- 使用两行以上的长地址测试，确认地址最多显示两行，精度、时间和按钮不被挤出屏幕。
