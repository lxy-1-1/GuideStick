# 智途位置地图页设计

## 目标

将当前位置页从纯文字信息升级为地图优先的定位界面。在不申请商业地图 Key、不改变手机定位来源的前提下，使用 Android `WebView` 内嵌 OpenStreetMap 地图，显示当前位置标记，并保留地址、坐标、精度和更新时间。

## 页面结构

1. 顶部保留“当前位置”工具栏。
2. 工具栏下方放置固定高度的交互地图，宽度占满页面内容区域。
3. 地图加载时显示进度提示；网络或网页加载失败时显示“地图暂时无法加载”，但不遮挡文字定位信息。
4. 地图下方依次显示地址、坐标、定位精度和更新时间。
5. 底部提供“刷新定位”和“打开地图”两个命令按钮。
6. 原有底部导航保持不变。

## 数据流

- `LocationManager` 继续获取手机 GPS/网络位置。
- `showLocation(Location)` 更新文字信息，同时调用 `MapUrlBuilder` 生成 OpenStreetMap 内嵌 URL 并加载到 `WebView`。
- “打开地图”优先发送 `geo:` Intent 给系统地图应用；没有可处理应用时回退到 OpenStreetMap 浏览器页面。
- 页面销毁时停止 WebView 加载并销毁实例，避免 Activity 泄漏。

## 安全与降级

- 地图只允许加载 HTTPS OpenStreetMap 页面。
- WebView 禁止文件访问和内容访问，仅启用地图页面所需 JavaScript 与 DOM 存储。
- 无定位权限、定位关闭或定位失败时不加载伪造位置。
- 地图加载失败不影响地址、坐标和紧急短信功能。
- 不引入地图 SDK、API Key、账户或额外付费服务。

## 验收

- JVM 测试覆盖地图边界、标记坐标和外部地图 URL。
- 定位成功后地图显示当前位置标记，刷新定位会更新地图。
- 无网络时显示地图失败状态，地址和坐标区域仍可使用。
- `testDebugUnitTest`、`lintDebug` 和 `assembleDebug` 通过。

## 非目标

- 不实现路线规划、实时导航、轨迹记录或电子围栏。
- 不宣称导盲杖内置 GPS。
- 不将位置上传到新的第三方业务服务器。
