# 智途地图页视觉重构设计

## 目标

减少当前位置页的无效空白，让地图成为页面主视图，同时保持地址、坐标和操作按钮清晰、稳定、适合户外与大字模式使用。

## 视觉方案

- 地图不再使用固定 `280dp` 高度，改为弹性占据工具栏、信息区和底部导航之外的全部剩余空间。
- 地图设置合理最小高度，普通手机上约占可用内容高度的 55% 至 65%。
- 信息区使用全宽浅色表面带，不添加浮动卡片、圆角容器或地图遮挡层。
- 地址字号从展示型大标题调整为紧凑标题，最多显示两行，超出使用省略号。
- 坐标保留单独一行；精度和更新时间合并为左右对齐的元数据行。
- “刷新”和“打开地图”保持并排、等宽和稳定高度，避免动态内容导致按钮位移。
- 地图加载与错误覆盖层继续使用，地图控件、版权信息和标记不得被业务 UI 遮挡。

## 响应式行为

- 大屏：地图获得更多高度，信息区保持内容所需高度。
- 小屏或大字模式：信息区按内容增长，地图缩小但不低于可操作下限。
- 地址较长时最多两行，不挤压坐标和按钮。
- 底部导航始终独立固定，不覆盖信息区按钮。

## 验收

- 普通竖屏截图中地图明显大于旧版，页面不再存在大块无效空白。
- 地址、坐标、精度、时间和按钮无重叠或截断。
- 地图缩放、刷新、外部地图跳转和底部导航行为不变。
- Android 单元测试、Lint 和 Debug APK 构建通过。

## 非目标

- 不更换 OpenStreetMap、不增加地图 SDK 或 API Key。
- 不改变定位精度、刷新频率和位置数据来源。
- 不修改其他客户端页面。
