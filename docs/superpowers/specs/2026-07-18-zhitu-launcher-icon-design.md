# 智途启动图标设计

## 目标

用统一、清晰且适合小尺寸显示的品牌图标替换人物剪影和 Android 默认启动图标。

## 视觉方案

- 深青绿色背景，与客户端主色 `#006C67` 一致。
- 白色圆角导航路线构成简化的 Z 形，表达“智途”和路径引导。
- 琥珀色终点圆点表达安全抵达，也与客户端强调色一致。
- 不使用人物、文字、渐变和细碎装饰，保证桌面小图标的辨识度。

## Android 资源

- 自适应图标：独立背景和前景，主体位于安全区域。
- 普通图标：圆角方形背景，适配 Android 7。
- 圆形图标：圆形背景，适配使用圆形图标的启动器。
- 单色图标：复用前景轮廓，支持 Android 主题图标。
- 关于页使用同一启动图标，不再单独维护旧 JPG。

## 验证

- Android 资源链接、Lint 和 Debug APK 构建通过。
- 检查图标在方形、圆形和自适应遮罩中的安全边距。
