# 智途 Android 客户端全面改版设计

## 目标

将现有 GuideSticks Android 客户端改造成适合视障出行场景和竞赛演示的稳定版本。改版保留现有业务能力，不改动 Django 已有接口契约，重点解决中文乱码、视觉不统一、状态反馈不足、网络地址写死、错误信息不明确和无障碍支持不足。

品牌统一为：

- 团队名称：智途
- 口号：智行无碍，途达万家
- 应用名称：智途导盲助手

“关于我们”不得出现成员姓名、学校、教师或其他个人信息。

## 设计原则

1. 无障碍优先：高对比、大触控区、明确状态语义、完整内容描述。
2. 安全优先：红灯、未知场景和紧急操作不能只依赖颜色表达。
3. 演示优先：首页直接呈现核心能力，减少层级和无效页面跳转。
4. 稳定优先：保留 Java + XML 架构，不迁移 Compose，不接入重型地图 SDK。
5. 真实反馈：禁止以假设备状态或假识别结果充当演示数据。

## 视觉系统

- 背景使用浅灰白，正文使用深灰黑，保证户外对比度。
- 主色使用青绿色，体现通行与辅助科技属性。
- 警示使用琥珀色，危险和紧急操作使用红色。
- 卡片圆角不超过 8dp，减少阴影，依靠分区和边框建立层次。
- 正文默认不低于 16sp，主要按钮高度不低于 56dp，图标按钮不低于 48dp。
- 所有中文文案集中在 `strings.xml`，清除 Java/XML 中的乱码和中英文混用。

## 信息架构

底部导航保留三项：

1. 首页：服务状态、核心功能入口、最近识别结果。
2. 位置：当前位置、经纬度、精度和手动刷新。
3. 我的：用户信息、紧急联系人、无障碍偏好、服务器设置、关于和退出。

### 首页

- 顶部展示“智途”和口号。
- 服务器状态区自动检测 Django 服务是否可达，并提供手动刷新。
- 出行助手作为首要入口，支持文字与语音对话。
- 红绿灯识别、寻找导盲杖、紧急呼叫使用独立大操作项。
- 最近一次识别结果使用文字、图标和语义色共同表达。

### 登录与注册

- 统一品牌、输入框和按钮样式。
- 表单在小屏和键盘弹出时可滚动。
- 提交期间禁用重复点击并显示加载状态。
- 注册和登录失败时解析并展示后端实际错误，不再统一显示“失败”。

### 出行助手

- 首次进入显示能力说明和常用问题快捷入口。
- 消息气泡区分用户与助手，保持高对比和合理最大宽度。
- 支持语音输入、发送、停止朗读和清空会话。
- 请求期间显示“正在分析”，防止重复发送。
- 网络失败保留问题，并提供明确的重试路径。
- TTS 是否自动朗读由无障碍设置控制。

### 红绿灯识别

- 保留手机摄像头预览和拍照上传流程。
- 增加相机准备、处理中、成功、未知、失败状态。
- 展示后端返回的 `light`、`command` 和 `message`，而不只显示英文颜色。
- 红灯、绿灯、未知结果分别使用红色、绿色、琥珀色，并始终带中文文字。
- 识别期间禁止重复拍照。

### 寻找导盲杖

- 明确显示正在发送、等待设备响应、已找到、超时和失败状态。
- 提供重试和取消按钮。
- 页面退出时停止轮询并取消未完成请求。

### 紧急呼叫

- 显示当前紧急联系人和服务监听状态。
- 手动拨号前确认，避免误触；硬件紧急信号仍按现有流程响应。
- 无电话功能、无权限、网络失败和拨号失败均使用中文解释。
- 紧急操作使用红色语义，不与普通主按钮混淆。

### 位置

- 不引入地图 SDK。
- 显示地址、经纬度、定位精度和更新时间。
- 支持手动刷新、定位权限拒绝和定位服务关闭提示。

### 我的与设置

- 用户信息、邮箱和紧急联系人清晰分组。
- 增加大字模式、助手自动朗读、触觉反馈开关。
- 增加服务器地址设置与连接测试，默认值保持现有 `http://172.20.10.3:8000/`。
- 修改服务器地址后重建 Retrofit 客户端，紧急呼叫轮询同步使用新地址。
- 退出登录只清除账号会话，不清除服务器和无障碍偏好。

### 关于我们

- 只展示团队名称“智途”、口号“智行无碍，途达万家”、项目定位、核心能力和隐私说明。
- 不展示任何成员、学校、教师、电话号码或其他身份信息。

## 代码结构

- `AppSettings`：持久化服务器地址和无障碍偏好。
- `BaseActivity`：应用大字模式和通用触觉反馈。
- `RetrofitClient`：按设置中的服务器地址创建客户端，统一超时配置。
- `ApiErrorParser`：提取 DRF 错误响应中的具体中文提示。
- 各 Activity 继续负责自己的页面交互，避免引入与当前规模不匹配的架构重构。
- 业务接口继续由现有 `ApiService` 管理，并增加轻量服务健康检查。

## 错误处理

- HTTP 4xx：显示后端字段错误或非字段错误。
- HTTP 5xx：显示服务暂时不可用，并允许重试。
- 无网络/超时：显示服务器地址和排查提示，不泄露 API Key。
- 权限拒绝：说明权限用途并保留返回路径。
- Activity 销毁：取消 Retrofit 请求、定位监听、相机任务和轮询回调。

## 测试与验收

1. JVM 单元测试覆盖对话历史、服务器地址规范化和 API 错误提取。
2. `testDebugUnitTest` 通过。
3. `assembleDebug` 通过并生成可安装 APK。
4. Android Lint 检查关键资源和无障碍问题。
5. 人工验收清单覆盖登录注册、首页状态、摄像头、助手语音、寻杖、紧急呼叫、定位、设置和关于页面。
6. 若本机无模拟器或设备，明确记录需要在实体手机验证的相机、麦克风、TTS、拨号和触觉反馈项目。

## 非目标

- 不在本次改版中迁移 Jetpack Compose。
- 不引入在线地图、导航路线规划或新的付费服务。
- 不改变 DeepSeek 的安全边界：安全通行判断继续由本地规则负责。
- 不伪造 XIAO ESP32S3、测距模块或其他尚未接入的硬件状态。
